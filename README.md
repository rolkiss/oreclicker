# Ore Clicker

Un clicker de minería en el navegador: pica la roca, compra 50 productores, desciende por 7 biomas, renace para ganar
Núcleos y habilidades, completa retos especiales y llena la Mineralpedia. Gratis y sin registro; en español e inglés.

**Jugar:** <https://oreclicker.com>

## Tu partida

Se guarda solo en tu navegador (no hay cuentas ni servidor). Desde Opciones puedes exportar un código de copia de seguridad
para llevarte la partida a otro dispositivo o navegador.

## Privacidad y anuncios

El juego muestra un banner de publicidad discreto solo si lo aceptas, y puedes cambiarlo cuando quieras en Opciones → Anuncios.
Los detalles están en la [política de privacidad](privacy.html). Dudas: contact@oreclicker.com

## Ejecutarlo en tu equipo

Es una web estática, sin dependencias ni compilación. Desde esta carpeta:

```bash
python -m http.server 5500
```

y abre <http://localhost:5500>.
